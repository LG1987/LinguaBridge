# v0.2.3 · 撤销回车触发

- **版本号**：`0.2.3`（patch）
- **上一版**：`0.2.2`
- **版本依据**：撤销 0.2.2 引入的 Enter 接管，恢复"仅按钮可触发"；接口与其它行为不变。
- **tag**：`v0.2.3`

## 变更

| 项目 | 0.2.2 | 0.2.3 |
|------|-------|-------|
| 触发方式 | 「译」按钮 + composer 内 Enter | **仅「译」按钮** |
| Enter 行为 | 中文草稿时被接管 | 完全交还 DSH 原生 |
| 键盘监听 | 捕获阶段监听 `keydown` | 无 |

需求方明确要求"这个按键无需触发"，因此把 0.2.2 的 Enter 接管整体移除；RC-002 在需求记录中标记为**已撤销**。

## 保留的行为

- 动画常驻在「译」按钮旁，2s 一圈无限循环。
- 点击后瞬间落到工具行最左（「完全权限 +」之后），再由 `@keyframes lb-sweep` 在 6s 内匀速滑回按钮旁。
- 结构性格式保护：代码块、行内代码、URL、邮箱、路径、命令、环境变量、`{{模板}}` 不进引擎。
- 失败不发送：引擎不可达、超时、空译文都保留草稿并在按钮旁报错。
- 忙碌态固定 6 秒；`submit()` 在等待前调用。
