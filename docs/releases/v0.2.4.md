# v0.2.4 · 动画去掉白色底板

- **版本号**：`0.2.4`（patch）
- **上一版**：`0.2.3`
- **版本依据**：纯视觉调整，只影响插件里加载动画的绘制。
- **tag**：`v0.2.4`

## 变更

| 项目 | 0.2.3 | 0.2.4 |
|------|-------|-------|
| 动画底板 | 26px 白色圆角方块 + 内阴影 | **透明**，无底板 |
| 背景混合 | `mix-blend-mode: darken` | 移除（依赖白底，透明后会压暗） |
| 方块滤镜 | `blur(5px) contrast(10) hue-rotate(300deg)` | 保留 |
| 观感 | 白色小方块里两个黄块粘合 | 直接看到两个黄块在粘合 |

## 为什么必须同时去掉混合模式

原 CSS 的"粘合"效果依赖三件事：纯白底、两个黄色伪元素、父级 `blur + contrast`。其中 `mix-blend-mode: darken` 是让黄块与**白色背景**混合的环节。底板一旦透明，`darken` 会把整块压向页面底色（深色主题下几乎全黑），所以必须一并移除，只保留滤镜链。
