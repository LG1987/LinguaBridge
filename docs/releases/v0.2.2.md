# v0.2.2 · 当前最新版

- **版本号**：`0.2.2`（patch）
- **上一版**：`0.2.1`
- **版本依据**：补一个缺失的触发路径（Enter），并合入 0.2.1 之后对动画的几轮修正；无接口变化。
- **tag**：`v0.2.2`

## 本版内容

### 1. 回车即翻译

在 DSH composer 里按 Enter，现在也会走"翻译 → 写回 → 提交"。

实现要点：在 `document` 的**捕获阶段**监听 `keydown`，命中以下全部条件才接管：

- `Enter` 且无 Shift/Ctrl/Alt/Meta
- 不在输入法组合期（`isComposing === false` 且 `keyCode !== 229`）
- 事件目标位于 `[data-lexical-editor="true"]` 内
- 当前草稿**含中文**
- 草稿不以 `/` 开头（斜杠命令）

命中时 `preventDefault()` + `stopPropagation()` 阻止站点原生发送，然后复用按钮同一条链路。英文草稿、斜杠命令、输入法组合中的 Enter 一律放行，原生行为不变。

### 2. 动画（合入 0.2.1 之后的修正）

| 项目 | 最终行为 |
|------|----------|
| 空闲 | 停在「译」按钮旁、同一行，持续运转（2s 一圈无限循环） |
| 点击 | 瞬间落到工具行最左（`完全权限 +` 之后 8px） |
| 移动 | 用 `@keyframes lb-sweep` 在 6s 内匀速滑回按钮旁 |
| 起点测量 | 向上找"跨整行的工具行"，取其第一个控件的右边缘；`[data-composer-card]` 在该构建里不存在 |
| 位移实现 | keyframes 而非 transition——同一帧切换 `transition: none → 6s` 时浏览器不启动过渡 |

## 已知限制

- Enter 接管只在**草稿含中文**时生效；纯英文输入按原生发送（这是有意的，避免每次回车都多一次翻译往返）。
- 6 秒忙碌期内「译」按钮为禁用态，不能连点。
- 接管发生在捕获阶段，若站点未来把发送绑定到 `keydown` 之外的路径（如按钮点击），该路径不受影响。
- 渲染进程直连 `127.0.0.1:5000`，若页面 CSP 收紧会失败并提示"连不上本地引擎"。
