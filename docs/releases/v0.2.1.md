### 动画的三处必要改造

原文件是给普通网页用的 `.loading-326`，直接搬进 DSH 有三个问题：

1. **类名冲突** → 全部改为 `lb-loader*`；
2. **`mix-blend-mode: darken` 在深色主题下会把整块变黑** → 外层加 44px 白色容器隔离混合层，动画 `scale(0.42)` 放入；
3. **100px 方块会撑破输入区布局** → 改为 `position: fixed` 悬浮条，浮在输入框上方，不参与 composer 布局。

另加 `prefers-reduced-motion: reduce` 时把循环放慢到 4s。
