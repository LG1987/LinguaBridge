# v0.3.0 · GLM-4-Flash 主翻译 + 本地 Argos 保底

- **版本号**：`0.3.0`（minor）
- **上一版**：`0.2.5`
- **版本依据**：新增一种翻译来源（在线 LLM 层）与质量闸门，既有接口不变（`/translate` 请求/响应形状兼容，只多字段）。
- **tag**：`v0.3.0`
- **方案全文**：[docs/plan-free-hybrid.md](../plan-free-hybrid.md)（本轮只落地其子集：GLM 直调 + 质量闸门 + 保底，MyMemory/缓存/批量接口留待后续）

## 动机

用户实测：`好了，把这个作为最新版，推送到库里。` 被 Argos 译成 `Okay, let's get this up to speed.`——两个关键动作（"作为最新版"、"推送到库里"）全部丢失。对照实验证明这是模型能力问题，调参不可救。改为 LLM 直译后：

```
GLM-4-Flash: OK, treat this as the latest version and push it to the repository.
```

## 实现

```
/translate 请求
    ▼
Gateway（service/gateway.py）
    ├─ ① GLM-4-Flash   open.bigmodel.cn，OpenAI 兼容；输出过质量闸门
    └─ ② argos-local   本地引擎，永久兜底
质量闸门（service/quality.py）：空 / 未翻译 / 中文残留 / too-long / too-short / 复读
```

- **同语言放行**：检测语言 == 目标语言时直接原样返回（`provider: passthrough`），不进引擎也不被闸门误判。
- **降级**：GLM 网络/额度/解析失败、或输出不过闸门 → 自动落到 Argos → 全挂才抛错。
- **GLM system prompt**：只输出译文、保持行数、数字/标识符/路径/代码逐字保留、忠实翻译禁止总结改写漏译；支持术语表（暂未接线）。

## 配置与安全

| 项 | 说明 |
|----|------|
| key 来源 | 环境变量 `LB_LLM_KEY` 优先，其次 `service/providers.local.json` 的 `glm_api_key` |
| 入库策略 | `providers.local.json` 已加入 `.gitignore`，**密钥永不进仓库**（已验证 HEAD 与源码目录干净） |
| 强制离线 | 环境变量 `LB_OFFLINE=1`（`/health` 的 `providers` 只剩 `argos-local`） |
| key 泄露提醒 | key 曾以明文出现在对话中，建议在智谱控制台轮换 |
