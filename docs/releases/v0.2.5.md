# v0.2.5 · 动画改色

- **版本号**：`0.2.5`（patch）
- **上一版**：`0.2.4`
- **版本依据**：纯视觉调整，只改加载动画的配色。
- **tag**：`v0.2.5`

## 取色来源

使用者提供了一张 78×41 的参考图。用 `System.Drawing` 逐像素统计（跳过透明与深色背景），出现最多的颜色是：

| 颜色 | 像素数 | 用途 |
|------|--------|------|
| `#d97757` | 328 | 方块亮面 |
| `#b9603f` | 112 | 方块暗面 |
| `#d87757` `#d77656` | 144 | 抗锯齿边缘（忽略） |

## 改动

```css
.lb-loader { filter: blur(5px) contrast(1.15); }        /* 去掉 hue-rotate，contrast 10 → 1.15 */
.lb-loader:before { background: #d97757; }
.lb-loader:after  { background: #b9603f; }
```

**为什么必须动滤镜**：原来的 `contrast(10)` 会把任何颜色推到通道极值（`#d97757` 会被推成接近纯红橙），`hue-rotate(300deg)` 还会整体偏移色相。想保住取样色，就只能把对比度收到接近 1 的值。代价是"粘连"感比原来弱一些——模糊仍在，两块重叠时依然会柔和地连在一起。
