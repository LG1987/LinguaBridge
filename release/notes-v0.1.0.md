# LinguaBridge v0.1.0

首个可运行版本：**完全本地**的中英双语提示词层。浏览器扩展 + 本机翻译引擎，不调用任何付费 API，提示词不离开本机。

## 亮点

- **先确认，再发送**：原文 / 译文并排对比，译文可编辑；只有点击「写入输入框」或「写入并发送」才会动你的草稿，不存在隐式发送。
- **代码不会被翻坏**：代码块、行内代码、URL、路径、命令、环境变量、`{{模板}}` 根本不进翻译引擎，而是从原串拼回，因此逐字还原。这不是"限制模型别乱改"，而是结构性保证。
- **约束词提示**：必须 / 不得 / 只输出 / 仅限 / 上下限 / 除非 / 保持 / 分步 / 指定语言 / 指定格式，共 10 组规则加否定词粗检，译后异常会摆在面板上。
- **回复双语**：助手回复下方插入独立译文卡片（可折叠、可复制），不改原 DOM，代码复制与工具调用展示不受影响。
- **输入法安全**：拼音组合期间与结束后 60 ms 内不读写编辑器，避免拼音碎片。
- **完全本地**：引擎只绑定 `127.0.0.1:5000`；扩展只申请 4 个 host，不含 `<all_urls>`。

## 安装

1. 解压 zip；
2. `edge://extensions` / `chrome://extensions` → 开发人员模式 → 加载解压缩的扩展 → 选 `LinguaBridge-0.1.0` 目录；
3. 本地引擎另装：`pwsh -File tools\install.ps1`，然后 `pwsh -File tools\start-engine.ps1`；
4. 打开 DSH 或 ChatGPT 页面，右侧出现「译」按钮即成功。

## 已知限制

- Argos 属传统 NMT，复杂否定与长句指代会走样；手动确认面板是产品底线。
- 术语表会切碎句子，短片段上偶发漏词。
- DSH **桌面版**无法加载扩展且 Web UI 只接受 `?token=` 链接；真实页面验收请用浏览器打开 `dsh web` 的地址。
- ChatGPT 适配器为 beta，未在真实站点验收。
- 未实现：OpenCC 简繁、设置页。
